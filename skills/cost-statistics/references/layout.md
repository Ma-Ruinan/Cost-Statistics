# 版式规范

- A4封面加一至两页正文。统一中文字体，正文约10.5至11磅，标题层级清楚。
- 深蓝表头、白字、浅灰或浅蓝交替底色；表格为Word原生表格，数字居中、指标名左对齐，边框浅灰。
- 两张条形图共用固定对象颜色，标注对象和数值，不仅靠颜色表达。图表不得裁切或压缩到标签难辨。
- 封面标题为成本统计报告，副标题不含AI Agent。正文不使用装饰块或大量空泛文字。
- 对象较多时可改横向正文，检查表宽、图表标签与正文页数。题目数量增加不扩展逐题页数。
- 渲染后逐页检查文字、表格、图片、页码和分页，修复越界、截断与异常留白。
