# 统计规则

## 数据关联

- 以题目来源与标准题号联合匹配，例如AlphaData、1-5。内部测试ID仅定位运行记录。题目名称用于核对，同号不同名时停止合并。
- 任务均值表提供各题均值与独立次数；逐次记录表提供每次耗时、调用量及日期。按表头和工作表名称读取，不依赖固定列序。
- 每个指标使用所有对象均取得该指标的共同题目。缺失保留空值，不补零；数值为0时正常计入。受影响指标的实际共同有效题数才需简短注明。
- 先按受测对象合并本次范围内的多份工作簿，再求所有对象的共同题目。表内对象标题优先于文件名；显式 `--input 对象名=路径` 可指定对象，同对象可重复指定。MobileWork、WorkBuddy、TeleAgent的名称忽略大小写。

## 同一对象多文件

- 不同数据集或不同题目的结果取并集，同一来源和题号只保留一个题目。各对象的文件数量、分工方式不需要一致。
- 文件内容摘要相同的副本只读取一份。跨文件同一次执行以会话ID与用户消息ID的组合识别；测试ID可能在不同人员的文件内重新编号，既不能单独用来去重，也不能据此把真实多次执行合成一次。不同对象的执行互不去重。
- 同题分散在多文件时使用完整逐次记录，按上述标识去重，再从各指标有效逐次值重算题目均值及独立次数。不能直接平均各文件的题目均值，也不能直接相加各文件的独立次数。某指标缺失不补零，真实0照常参与。
- 同一执行的重复记录数值一致时计一次；一份缺失、另一份有值时使用已取得值。已有数值或起止时间冲突时停止并定位文件，不自动选较新、较大或较小的数值。来源、题号或题目名称冲突也须核实。
- 不重叠题目可沿用其任务均值；缺少逐次表时相应执行不参与分位数。重叠题目若缺少完整逐次记录、会话ID或用户消息ID，停止合并该次输入并定位缺项，不猜测执行次数。逐次表存在时必须与题目均值表的执行次数、已取得均值一致。
- P50、P95及派生比率使用合并去重后的逐次值。合并文件、文件摘要、去重数量和逐次来源保存在汇总JSON；不在报告增加例行说明。不同测试批次是否纳入由用户指定的目录或文件范围决定。

## 指标计算

| 指标 | 计算规则 |
| --- | --- |
| 平均输入Token、平均输出Token | 先对同题各次运行求均值，再对共同题目等权平均。输入沿用采集工作簿口径。 |
| 平均总Token | 同一有效题目上的输入与输出相加，再按题目等权求均值。 |
| 平均端到端耗时 | 同题运行均值后按题目等权；Excel时长数值以一天为单位，内部乘86400计算。 |
| 端到端耗时P50、P95 | 对共同题目的有效逐次耗时排序，使用PERCENTILE.INC线性插值：位置为(n-1)p，取相邻两值插值。不能对题目均值计算分位数，也不能平均各题分位数。 |
| 平均LLM完成调用数 | 任务均值按题目等权平均。 |
| 平均缓存命中率 | 沿用各题缓存命中率，再对共同题目等权平均。不能用总体输入加权比例替代。 |
| 平均工具调用数、平均工具错误次数 | 各题运行均值按题目等权平均。 |

Token展示单位为万，保留4位小数；内部使用原始Token量。调用均值保留2位小数；命中率保留2位百分比小数。耗时按时分秒展示，最终四舍五入至秒。

分位数所需逐次表不存在时不推算，保持未取得。公式缺少缓存值时先在可用Office引擎重算副本，不更改原件、不把空缓存当0。工作簿中已标记未取得的指标按缺失处理。

## 派生分析

单次LLM平均输入量使用有效逐次记录的累计输入除以累计完成调用数；工具错误占比使用累计错误次数除以累计工具调用数。只使用分子与分母均存在的同一组记录，分母为0时不生成比率。跨对象均值差异用同一有效题集；不能将不同指标缺失造成的题集变化解释为产品差异。

汇总JSON保留输入文件摘要、共同题目、逐指标有效题数、运行次数及实际问题。正文只保留理解结果所需的事实，不输出核查日志。
