# 报告内容

封面记录对象、数据集范围、共同题目数、各对象运行次数、可取得的测试日期和报告日期。标题为成本统计报告，副标题为执行过程消耗对比。

正文第一部分为十项指标横向对比表：平均输入Token、平均输出Token、平均总Token、平均端到端耗时、端到端耗时P50、端到端耗时P95、平均LLM完成调用数、平均缓存命中率、平均工具调用数、平均工具错误次数。表下简短介绍均值、总Token、调用与错误口径及分位数算法，不写软件实现细节。

第二部分用两张横向条形图呈现平均总Token和平均端到端耗时。对象顺序、颜色和表格一致，坐标、单位、数值标签齐全。随后保留两至三条重要发现，说明数值之间的关系；有数据时适度增加MobileWork的具体观察。分析不预设结论，不将成本统计扩展为内容质量评价。

不要加入逐题表、数据来源章节、引用文件路径、固定的小样本提示、保护性声明或后续工作计划。没有需要说明的异常时正常呈现结果，不为每个结论添加限制性尾句。不使用双引号或破折号。

分析根据实际数据选择，例如调用次数更少但Token更多时结合单次输入规模解释，均值与中位数排序不一致时结合P95解释，工具调用数量与错误次数排序不同时结合累计错误占比解释。不要求每份报告固定采用这些主题。
